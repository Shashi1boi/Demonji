2. Worker Playlist (.mpd)

Points at your worker's /S2/mpd/{id} URLs. Works on Tizen players that support DASH (tizenbrew-bajawaiptv, ThePlay).

3. HLS Playlist (.m3u8)

Builds native JioTV HLS URLs from channel names. May require auth tokens on some channels. Use this if your Tizen app only accepts .m3u8.

⚠ Native HLS URLs use the legacy JioTV CDN pattern. If channels don't load on your TV, use the Worker playlist (.mpd) instead — most Tizen players support DASH.

4. How to use on Samsung Tizen

Option A — TizenBrew (tizenbrew-bajawaiptv):
1. Download jio_worker.m3u to a USB drive or host it online
2. Open tizenbrew-bajawaiptv on your Samsung TV
3. Load the playlist from USB or paste the URL
4. It supports DASH + HLS natively — both playlists should work

Option B — Smart IPTV / m3u-ip.tv:
1. Host the .m3u file on a URL (GitHub Gist raw, pastebin raw, your worker, etc.)
2. Open Smart IPTV → add the M3U URL
3. Use the HLS playlist if Smart IPTV rejects DASH

✓ Tip: Host the generated .m3u file and paste the raw URL into your TV app — no USB needed.
